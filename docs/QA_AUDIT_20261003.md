## 수정과 기능 보존

- 전체 갱신 수집이 끝났는지를 완료 콜백에 전달한다. 중간 취소/예외에서 갱신 표시를 정리하되 성공으로 표시하지 않는다. 정상 전체 완료·빈 목록·다중 계정 대기·호스트 오류 후 저장 결과 보존 테스트도 유지했다.
- 기존 `UNMETERED` 네트워크 정책과 저장된 `wifiOnly` 키를 유지했다. 한국어/영어 UI 이름을 비과금 네트워크로 정정하고 수동 갱신 예외를 설명한다. 과금/비과금 및 자동 갱신 끄기를 시험했다.
- 기존 계정별 WebView 세션 격리, 로그아웃 후 새 프로필, 다른 계정 데이터 보존, DB 마이그레이션, 마지막 정상 snapshot 유지, 동시 갱신, 갱신 중 대표 한도 변경을 Android에서 검증했다.
- 실제 부착된 위젯의 터치로 WorkManager를 실행해 두 계정 갱신과 값 반영을 확인했다. 다양한 크기에서 0/100/알 수 없음/오류 표시와 화면 여정도 통과했다.
- PR 검증은 배포 서명을 요구하지 않는다. 신뢰된 push/수동 실행의 서명 절차와 release 흐름을 유지하며 성공한 검증의 소스 SHA·APK SHA256 manifest를 산출물과 릴리스에 남기도록 했다. GitHub 실행 자체는 이번 로컬 검증에 포함되지 않는다.
- Windows 검증 스크립트는 AVD 이름까지 검사해 `eslee_qa_api35`에만 설치한다.
