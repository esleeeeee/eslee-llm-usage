# v0.1.4 로그인 및 사용량 인식 수정 기록

기준: v0.1.3 / c88c035. 작업일: 2026-09-10. Android-only 유지.

## 사용자 보고와 확인한 원인

- Codex 로그인 후 ChatGPT 홈에 머묾: 기존 코드는 페이지 로드 완료 시 사용량 URL만 검사했고, 로그인 후 SPA 화면 변화를 지속적으로 관찰하거나 홈에서 Usage로 자동 이동하지 않았다.
- 화면에는 사용량이 있지만 앱은 unknown: 한국어 `주간 사용 한도`와 줄바꿈된 `% / 남음`, 한국어 날짜를 기존 파서가 처리하지 못했다.
- 인증 팝업: 기존 팝업은 해당 계정 profile에 연결하지 않았고, 팝업 URL을 메인 창에 로드한 뒤 팝업을 즉시 파괴했다. OAuth opener와 인증 창의 수명 유지가 깨지는 구현이었다.
- Google 2차 인증 알림 미수신 및 Grok device verification 대기는 실제 기기/Provider 인증 결과로 원인을 확정하지 못했다. 아래 수정이 해당 현상을 모두 해결했다고 판정하지 않는다.

## 구현

1. 계정 profile을 인증 팝업에도 연결하고, 보안 설정과 내비게이션 검사를 적용한다. 팝업을 실제 화면에 유지하며 닫기/뒤로가기를 지원한다. profile의 CookieManager를 사용한다.
2. 로그인 후 화면 상태를 관찰해 Usage URL로 이동한다. Usage 콘텐츠가 늦게 나타나거나 변하면 다시 읽는다. 파싱은 정확한 HTTPS Usage 경로에서만 실행한다.
3. 파서 1.2.0은 한국어 5시간/주간 한도, 줄바꿈된 used/remaining, 한국어 초기화 시각, 0 크레딧을 처리한다. 시간대 없는 한국어 시간은 휴대폰 기본 시간대를 사용한다.
4. 사용자 화면 fixture는 45%/66% 남음을 각각 55%/34% 사용으로 정규화한다. 할인 40%와 재설정권 만료일은 사용량으로 삼지 않는다.
5. 표시된 progress 요소의 aria-label/aria-valuetext도 추출한다.
6. 인증이 계속 막히면 외부 브라우저에서 Usage를 열고 표시 텍스트를 앱에 붙여넣을 수 있다. USER_ENTERED 출처로 저장한다. 자동 갱신/브라우저 세션 이전 기능은 아니다.

## 검증 범위

- 단위 테스트: 한국어 실제 표현, 영문 ARIA 문맥, reset-only PARTIAL, 정확한 Usage 경로와 로그인 판정 회귀 포함.
- 실제 Google 2차 인증 알림, Grok 로그인 완료, Android 화면/키보드/팝업 조작, 위젯 표시, 업데이트 설치: 연결 기기 없어 미실행.
- 최종 명령 결과는 BUILD_REPORT.md에 기록한다.

## 휴대폰 확인 순서

1. GitHub의 v0.1.4 APK를 기존 v0.1.3 위에 업데이트한다. 기존 데이터 삭제 없이 진행한다.
2. Codex 계정에서 로그인 후 자동 Usage 이동과 5시간/주간 잔여량, 초기화 시각, 크레딧을 확인한다.
3. 계정 창을 닫았다 다시 열어 세션 유지와 사용량 갱신을 확인한다.
4. Grok 이메일 로그인에서 device verification을 지나 Usage까지 도달하는지 확인한다. 여전히 멈추면 해결 완료가 아니다.
5. 소셜 인증이 막히면 기본 브라우저에서 해당 계정으로 로그인하고 Usage 텍스트를 복사해 앱에 붙여넣는다. 계정 선택이 같은지 확인하고 상세 화면의 사용자 입력 출처와 위젯 숫자를 확인한다.

## 참고

Google은 개발자가 제어하는 embedded user-agent의 OAuth를 제한한다. 이는 인증 알림 미수신의 개별 원인이 입증됐다는 뜻은 아니다. 기본 브라우저 로그인 세션을 WebView로 복사하는 공식 경로가 확인되지 않았으므로 쿠키/토큰 이식과 UA 위장은 구현하지 않았다.
